= Gerencie clones de banco de dados no NetApp Workload Factory for Databases
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Gerencie seus clones de sandbox no NetApp Workload Factory for Databases para manter seus ambientes de desenvolvimento e teste confiáveis e econômicos. Verifique se os dados de um clone estão intactos, conecte um clone ao seu pipeline de CI/CD para automatizar a entrega de software ou atualize, reverta ou divida um clone para alinhá-lo às suas necessidades de desenvolvimento atuais. Quando não precisar mais de um clone, exclua-o para liberar capacidade de storage.



[[check-sandbox-data-integrity]]
== Verifique a integridade de dados do sandbox

Execute uma verificação de integridade para determinar se os dados do clone de sandbox estão intactos ou corrompidos no NetApp Workload Factory for Databases.

.Sobre esta tarefa
Ao criar um clone de sandbox a partir de um banco de dados de origem enquanto este está ocupado, os dados do clone podem não estar sincronizados com o Snapshot mais recente do banco de dados de origem. Esta operação verifica a integridade de todos os objetos no clone de sandbox para determinar se os dados do clone de sandbox estão atualizados.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Cargas de trabalho* > *Bancos de dados*.
. No menu Databases, selecione *Sandboxes*.
. No Sandboxes, selecione o menu de ações do clone de sandbox cuja integridade você quer verificar.
. Selecione *Run integrity check*.
. Na caixa de diálogo Verificação de integridade, clique em *Verificação de integridade*.
. Verifique o status da verificação de integridade em Sandboxes ou no monitoramento de tarefas.


Se a verificação de integridade falhar, recomendamos que você não use o clone de sandbox e crie um novo clone de sandbox.



[[connect-a-sandbox-clone-to-cicd]]
== Conecte um clone de sandbox ao CI/CD

Conecte um clone de sandbox a um pipeline de integração contínua e entrega contínua (CI/CD) com código da API REST para melhorar a entrega de software por meio da automação na NetApp Workload Factory for Databases.

.Sobre esta tarefa
Para entregar automaticamente uma nova versão de software ao seu clone de banco de dados, você deve se conectar a um pipeline de CI/CD. Use o código da API REST fornecido por esta operação para fazer a conexão.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Cargas de trabalho* > *Bancos de dados*.
. No menu Databases, selecione *Sandboxes*.
. No Sandboxes, selecione o menu de ações do clone do sandbox para se conectar às ferramentas de CI/CD.
. Selecione *Conectar às ferramentas de CI/CD*.
. Na caixa de diálogo CI/CD, copie ou baixe o código da API REST necessário para se conectar às ferramentas de CI/CD.
. Clique em *Close*.




[[delete-a-database-clone]]
== Excluir um clone do banco de dados

Exclua um clone de sandbox no NetApp Workload Factory for Databases quando não precisar mais dele e quiser liberar capacidade de storage.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Cargas de trabalho* > *Bancos de dados*.
. No menu Databases, selecione *Sandboxes*.
. No Sandboxes, selecione o menu de ações do clone de sandbox que você deseja excluir.
. Selecione *Delete*.
. Na caixa de diálogo Delete, selecione *Delete* para confirmar a exclusão.




[[refresh-a-database-clone]]
== Atualizar um clone do banco de dados

Atualize um clone de banco de dados (sandbox) na NetApp Workload Factory for Databases para que ele seja equivalente ao banco de dados de origem no momento atual ou em um ponto anterior no tempo.

.Sobre esta tarefa
Atualizar um clone atualiza o clone para o banco de dados de origem no momento atual ou para um snapshot do banco de dados de origem obtido em um momento anterior. Quaisquer alterações feitas no clone de sandbox serão excluídas.

.Antes de começar
A atualização só é possível quando o banco de dados de origem está ativo.

Para atualizar um clone de banco de dados a partir de um snapshot, o banco de dados de origem deve ter pelo menos um snapshot para a operação.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Cargas de trabalho* > *Bancos de dados*.
. No menu Databases, selecione *Sandboxes*.
. Em Sandboxes, selecione o menu de ações do clone do sandbox que você deseja atualizar.
. Selecione *Atualizar*.
. Na caixa de diálogo Refresh, selecione uma das seguintes opções:
+
.. *Atualizar para a hora atual*
.. *Atualizar para um ponto específico no tempo*
+
Para esta opção, selecione o instantâneo do banco de dados no menu suspenso para o qual deseja atualizar.



. Clique em *Atualizar*.




[[revert-a-database-clone]]
== Reverter um clone do banco de dados

Reverter um clone de banco de dados (sandbox) para sua versão original no momento da criação no NetApp Workload Factory for Databases.

Ao clonar um banco de dados, o clone criado é um clone _baseline_. Os dados no banco de dados clonado são os mesmos do banco de dados de origem no momento da criação. Como os dados em um clone de banco de dados mudam com o tempo, você pode querer reverter os dados para a baseline de quando o clone foi criado pela primeira vez. Essa operação é chamada de redefinir a baseline de um clone. Redefinir a baseline de um clone, em vez de criar um novo clone, economiza espaço; no entanto, todas as alterações feitas no clone do banco de dados serão excluídas.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Cargas de trabalho* > *Bancos de dados*.
. No menu Databases, selecione *Sandboxes*.
. Em Sandboxes, selecione o menu de ações do clone do banco de dados que você deseja reverter.
. Selecione *Redefinir linha de base*.
. Na caixa de diálogo Re-baseline, selecione *Re-baseline*.




[[split-a-database-clone]]
== Dividir um clone de banco de dados

No NetApp Workload Factory for Databases, dividir um clone de banco de dados do banco de dados de origem cria um novo banco de dados que consumirá uma certa quantidade de capacidade de storage. O clone é excluído quando a divisão é concluída e o novo banco de dados aparece no Inventory.

.Antes de começar
Considere quanta capacidade de storage é necessária para o novo banco de dados. Se necessário, link:../fsx-storage/adjust-file-system-capacity.html["aumentar a capacidade do sistema de arquivos"^]calcule também a capacidade do sistema de arquivos FSx for ONTAP antes de começar.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Cargas de trabalho* > *Bancos de dados*.
. No menu Databases, selecione *Sandboxes*.
. Em ambientes de teste (Sandboxes), selecione o menu de ações do clone do banco de dados que você deseja dividir.
. Selecione *Dividir*.
. Na caixa de diálogo Split, selecione *Split*.




[[view-a-clones-connection-information]]
== Veja as informações de conexão de um clone

Visualize e copie as informações de conexão de um clone de banco de dados no NetApp Workload Factory for Databases.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Cargas de trabalho* > *Bancos de dados*.
. No menu Databases, selecione *Sandboxes*.
. Em ambientes de teste (Sandboxes), selecione o menu de ações do clone do ambiente de teste para visualizar suas informações de conexão.
. Selecione *Mostrar informações de conexão*.
. Na caixa de diálogo Mostrar informações de conexão, copie as informações de conexão se necessário.
. Selecione *Fechar*.
