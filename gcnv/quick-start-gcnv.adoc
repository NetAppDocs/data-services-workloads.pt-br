= Guia rápido para Google Cloud NetApp Volumes
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Comece a usar o Google Cloud NetApp Volumes atribuindo sua função no NetApp Console, adicionando credenciais e descobrindo um sistema.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-1.png["Um"] link:../gcnv/add-roles.html["Atribuir funções"]
[role="quick-margin-para"]
No NetApp Console, atribua as funções corretas aos membros.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-2.png["Dois"] link:https://docs.netapp.com/us-en/data-services-workloads/gcnv/add-credentials.html["Adicionar credenciais"]
[role="quick-margin-para"]
No NetApp Console, adicione as credenciais do Google Cloud NetApp Volumes.

.image:https://raw.githubusercontent.com/NetAppDocs/common/main/media/number-3.png["Três"] link:../gcnv/create-discover-systems.html["Adicionar um sistema"]
[role="quick-margin-para"]
No NetApp Console, descubra um sistema usando as credenciais, o projeto do Google Cloud e a região compatível.
