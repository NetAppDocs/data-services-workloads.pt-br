= Explore o centro de planejamento da VMware
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
O centro de planejamento da VMware permite que você carregue novos dados de inventário de VMs e crie novos planos de migração, além de gerenciar os dados de inventário de VMs e os planos de migração que você já salvou com NetApp Workload Factory.



[[manage-vm-inventory-data]]
== Gerenciar dados de inventário de VM

Use o centro de planejamento para criar e gerenciar dados de inventário de VMs.



[[upload-vm-inventory-data]]
=== Fazer upload dos dados de inventário de VMs

Você pode carregar os dados do inventário de VMs quando estiver pronto para usar o Workload Factory para explorar as opções de migração para ambientes Amazon AWS. Consulte link:upload-vm-inventory.html["Fazer upload dos dados de inventário de VMs"] para obter instruções.



[[rename-a-dataset]]
=== Renomear um conjunto de dados

Você pode alterar o nome de um conjunto de dados salvo.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Workloads* > *VMware*.
+
O centro de planejamento é exibido.

. Selecione o menu Ações (...) para o conjunto de dados que deseja renomear e selecione *Renomear*.
. Insira um novo nome para o conjunto de dados e selecione *Salvar*.




[[delete-a-dataset]]
=== Excluir um conjunto de dados

Quando um conjunto de dados não for mais necessário, você poderá excluí-lo a qualquer momento.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Workloads* > *VMware*.
+
O centro de planejamento é exibido.

. Selecione o menu Ações (...) para o conjunto de dados que deseja excluir e selecione *Excluir*.
. Selecione *Excluir* para confirmar a ação.




[[manage-migration-plans]]
== Gerenciar planos de migração

Use o centro de migração para criar e gerenciar planos de migração.



[[provision-a-migration-plan]]
=== Crie um plano de migração

Você pode selecionar um plano de migração e provisioná-lo para que as VMs migrem para o ambiente Amazon AWS de sua escolha.

.Passos
. Faça login no Workload Factory usando um dos https://docs.netapp.com/us-en/workload-setup-admin/console-experiences.html["experiências de console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até cargas de trabalho como armazenamento, eda, ai, bancos de dados, vmware e administração."] e depois selecione *VMware*.
+
O centro de planejamento é exibido.

. Selecione *Planos de migração*.
. Selecione o menu Ações (...) para o plano de migração que deseja provisionar e selecione *Provisionar*.
. Dependendo do plano de migração, consulte as instruções para implantar o sistema de arquivos:
+
** link:deploy-fsx-file-system.html["Implante o sistema de arquivos para planos do Amazon VMware Cloud"]
** link:deploy-fsx-file-system-native.html["Implante o sistema de arquivos para planos do Amazon EC2"]
** link:deploy-fsx-file-system-evs.html["Implante o sistema de arquivos para planos do Amazon Elastic VMware Service"]






[[edit-the-comment-for-a-migration-plan]]
=== Edite o comentário para um plano de migração

Se precisar alterar os detalhes de um comentário em um plano de migração, edite o comentário diretamente na central de planejamento.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Workloads* > *VMware*.
+
O centro de planejamento é exibido.

. Selecione *Planos de migração*.
. Selecione o menu Ações (...) do plano de migração que você deseja editar e selecione *Editar comentário*.
. Digite um comentário e selecione *Salvar*.




[[create-a-pdf-or-csv-report-of-a-migration-plan]]
=== Crie um relatório em PDF ou CSV de um plano de migração

Crie um relatório em PDF ou CSV com os detalhes de um plano de migração.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Workloads* > *VMware*.
+
O centro de planejamento é exibido.

. Selecione *Planos de migração*.
. Selecione o menu Ações (...) do plano de migração para o qual você deseja criar um relatório em PDF ou CSV e selecione *Baixar plano (PDF)* ou *Baixar relatório da VM (CSV)*.
. Insira um nome para o relatório e selecione *Salvar*.




[[delete-a-migration-plan]]
=== Excluir um plano de migração

Quando um plano de migração não for mais necessário, você poderá excluí-lo a qualquer momento.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Workloads* > *VMware*.
+
O centro de planejamento é exibido.

. Selecione *Planos de migração*.
. Selecione o menu Ações (...) para o plano de migração que você deseja excluir e selecione *Excluir*.
. Confirme a ação selecionando *Delete*.
