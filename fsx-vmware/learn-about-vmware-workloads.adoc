= Saiba mais sobre o NetApp Workload Factory para VMware
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
NetApp Workload Factory for VMware fornece ferramentas para migrar seus dados de sistemas locais para Amazon Elastic VMware Service (Exchange Virtual Server), VMware Cloud on AWS (VMC), Amazon EC2 ou Google Cloud VMware Engine.



[[what-is-netapp-workload-factory-for-vmware]]
== O que é o NetApp Workload Factory for VMware?

NetApp Workload Factory para VMware oferece um centro de planejamento e consultores de migração que permitem analisar as configurações atuais de suas máquinas virtuais em ambientes locais vSphere. Os consultores de migração então geram um plano para implantar layouts de máquinas virtuais recomendados no Amazon Exchange Virtual Server, Amazon EC2, clusters VMware Cloud on AWS vSphere ou Google Cloud VMware Engine, usando armazenamento nativo da nuvem personalizado como datastores externos. Para ambientes AWS, isso inclui Amazon FSx for NetApp ONTAP file systems. Para ambientes Google Cloud, isso inclui Google Cloud NetApp Volumes. O centro de planejamento, atuando como o painel do Workload Factory para VMware, permite gerenciar conjuntos de dados de inventário de máquinas virtuais salvos, planos de migração salvos e provisionar qualquer um dos planos de migração que você salvou.

Amazon FSx for NetApp ONTAP é um datastore NFS externo construído no sistema de arquivos ONTAP da NetApp, que pode ser conectado a instâncias do Amazon EVS ou Amazon EC2 ou a clusters do VMware Cloud on AWS vSphere. Da mesma forma, o Google Cloud NetApp Volumes fornece datastores NFS externos para ambientes do Google Cloud VMware Engine. Não é necessário adicionar mais hosts para aumentar a capacidade de storage disponível; basta usar esses volumes de storage nativos da nuvem como datastores externos para complementar os datastores vSAN. Isso proporciona uma infraestrutura de storage virtualizada, flexível e de alto desempenho, que escala independentemente dos recursos computacionais.

Para obter mais informações sobre o Workload Factory, consulte o link:../setup/learn-about-workload-factory.html["Visão geral do Workload Factory"^].



[[how-the-vmware-migration-advisors-work]]
== Como funcionam os consultores de migração da VMware

Os consultores de migração podem ajudar você a mover máquinas virtuais (VMs) locais e seus dados, executadas em qualquer datastore compatível com VMware, para datastores do Amazon Exchange Virtual Server, Amazon EC2, VMware Cloud ou Google Cloud VMware Engine, o que inclui datastores NFS suplementares em um sistema de arquivos FSx for ONTAP ou Google Cloud NetApp Volumes.

Observe que você pode conectar até quatro (4) volumes do FSx for ONTAP a um único cluster vSphere no VMware Cloud on AWS.



[[what-you-can-do-with-the-migration-advisors]]
== O que você pode fazer com os consultores de migração

Os consultores de migração oferecem as seguintes funcionalidades:

* Analisar as configurações atuais de VMs locais
* Determine quais VMs migrar para Amazon EC2, Amazon Exchange Virtual Server, VMware Cloud on AWS ou Google Cloud VMware Engine
* Identifique o espaço necessário nos volumes de storage nativos da nuvem para serem usados como datastores externos de máquina virtual
* Analise o relatório resultante para compreender as etapas de implantação
* Realizar a implantação propriamente dita (para Amazon EC2, Amazon Exchange Virtual Server e VMware Cloud on AWS)


O assistente de migração oferece suporte ao planejamento de configuração para um único Amazon EVS, Amazon EC2 ou cluster VMware Cloud on AWS conectado a Amazon FSx for NetApp ONTAP sistemas de arquivos, ou um cluster Google Cloud VMware Engine conectado ao Google Cloud NetApp Volumes.



[[benefits-of-using-the-migration-advisors]]
== Benefícios de usar os consultores de migração

A migração de partes da sua infraestrutura atual para Amazon EC2, Amazon Exchange Virtual Server, VMware Cloud on AWS ou Google Cloud VMware Engine usando armazenamento nativo da nuvem como NFS datastores externos oferece os seguintes benefícios:

* Otimização de custos devido ao desacoplamento entre host e armazenamento e à eficiência avançada de dados
* Capacidade de expandir a capacidade de storage conforme necessário, sem a necessidade de adquirir instâncias de host adicionais
* NetApp ONTAP oferece recursos de gerenciamento de dados na nuvem, como snapshots com uso eficiente de espaço, clonagem, compressão, deduplicação, compactação e replicação
* Redução na gestão de atualizações de hardware
* Capacidade de alterar a taxa de transferência de dados, IOPS e o tamanho do sistema de arquivos, além de aumentar ou diminuir o tamanho dos volumes
* Alta disponibilidade com suporte para implantações em múltiplas Zonas de Disponibilidade (AZ)
* Redução de custos e latência em configurações de AZ única que usam peering de VPC sem exigir um Transit Gateway




[[tools-to-use-netapp-workload-factory]]
== Ferramentas para usar o NetApp Workload Factory

Você pode usar o NetApp Workload Factory com as seguintes ferramentas:

* *Workload Factory console*: o Workload Factory console fornece uma visão visual e holística dos seus aplicativos e projetos.
* *NetApp Console*: o NetApp Console oferece uma experiência de interface híbrida para que você possa usar o Workload Factory juntamente com outros serviços de dados da NetApp.
* *Ask me*: use o assistente de IA Ask me para fazer perguntas e saber mais sobre o Workload Factory sem sair do console do Workload Factory. Acesse o Ask me no menu de ajuda do Workload Factory.
* *CloudShell CLI*: o Workload Factory inclui uma CLI do CloudShell para gerenciar e operar ambientes da AWS e da NetApp em várias contas a partir de uma única CLI baseada em navegador. Acesse o CloudShell na barra superior do console do Workload Factory.
* *APIs REST*: use as APIs REST do Workload Factory para implantar e gerenciar seus sistemas de arquivos FSx for ONTAP e outros recursos da AWS.
* *CloudFormation*: Use o código do AWS CloudFormation para executar as ações que você definiu no console do Workload Factory para modelar, provisionar e gerenciar recursos da AWS e de terceiros a partir da pilha do CloudFormation na sua conta AWS.
* *NetApp Terraform provider*: Use o Terraform para criar e gerenciar fluxos de trabalho de infraestrutura gerados no console do Workload Factory.




[[well-architected-analysis-for-evs-environments]]
== Análise bem arquitetada para ambientes Exchange Virtual Server

A aba Well-architected fornece análises diárias automatizadas dos seus ambientes do Amazon Elastic VMware Service (Exchange Virtual Server) para garantir o alinhamento com as melhores práticas da AWS e da NetApp. A aba identifica problemas de configuração e fornece orientações detalhadas para correção, ajudando você a manter operações, segurança e eficiência de custos ideais.

As varreduras automáticas são realizadas usando APIs da AWS—nenhuma vSphere credencial é necessária. Os resultados são organizados por área de configuração, com cada resultado incluindo status, níveis de gravidade, detalhes dos recursos afetados e procedimentos de correção passo a passo.

link:view-evs-well-architected.html["Implemente configurações Exchange Virtual Server bem arquitetadas no Workload Factory"].



[[cost]]
== Custo

O uso do Workload Factory para VMware é gratuito.

Você precisará pagar pelos recursos da AWS que implantar com base nas recomendações dos consultores de migração.



[[licensing]]
== Licenciamento

Nenhuma licença especial da NetApp é necessária para usar o Workload Factory para VMware.



[[regions]]
== Regiões

O Workload Factory é compatível com todas as regiões comerciais onde o FSx for ONTAP é compatível. https://aws.amazon.com/about-aws/global-infrastructure/regional-product-services/["Veja as regiões da Amazon suportadas."^]

As seguintes regiões da AWS não são suportadas:

* Regiões da China
* Secret Cloud
* Top Secret Cloud
