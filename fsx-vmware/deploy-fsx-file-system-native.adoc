= Implante o sistema de arquivos FSx for ONTAP recomendado
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Após verificar se o sistema de arquivos FSx for ONTAP recomendado (ou vários sistemas de arquivos, em alguns casos) atende aos seus requisitos exatos, você pode usar o Workload Factory para implantar o sistema no seu ambiente AWS.

Siga as instruções em link:../fsx-storage/create-discover-systems.html["Crie um sistema de arquivos do FSx for ONTAP na NetApp Workload Factory"^] para implantar o sistema de arquivos FSx for ONTAP de acordo com a configuração recomendada pela Workload Factory. Você pode usar as etapas de *Advanced create* nas instruções para personalizar totalmente o sistema de arquivos.
