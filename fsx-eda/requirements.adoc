= Workload Factory para requisitos de EDA
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Certifique-se de que o NetApp Workload Factory e a AWS estejam configurados corretamente antes de usar o NetApp Workload Factory para EDA. Isso inclui ter suas credenciais de login da AWS, um sistema de arquivos FSx for ONTAP implantado e muito mais.

Login e conta do Workload Factory:: Você precisará link:../setup/sign-up-and-log-in.html["Cadastre-se e faça login no NetApp Console."]
Credenciais e permissões da AWS:: Você precisa adicionar credenciais da AWS ao Workload Factory com permissões de leitura/gravação, o que significa que você usará o Workload Factory no modo _leitura/gravação_ para EDA.


Os modos _Basic_ e _Read-only_ não são suportados no momento.


NOTE: As credenciais da AWS também são necessárias para usar o recurso de monitoramento de latência, que coleta métricas do CloudWatch para análise de desempenho de volume. Para receber notificações de eventos de latência, configure as preferências de notificação nas configurações do Workload Factory. A análise opcional de IA para cenários complexos de latência está disponível quando a análise de IA gerenciada pela NetApp está habilitada. link:learn-latency-monitoring.html["Saiba mais sobre monitoramento de latência"].

link:../fsx-storage/add-credentials.html["Aprenda como adicionar credenciais da AWS ao Workload Factory."]

Sistema de arquivos FSx para ONTAP:: Você precisa de no mínimo um sistema de arquivos FSx for ONTAP:
+
--
* O sistema de arquivos será usado pelo EDA para armazenar os projetos e espaços de trabalho que você criar.
+
Este sistema de arquivos FSx for ONTAP deve usar volumes FlexVol. FlexGroup volumes não são suportados.

* Você precisará saber a região da AWS, a VPC e a sub-rede onde reside o sistema de arquivos AWS FSx for ONTAP.
* Você precisará de pelo menos um volume no sistema de arquivos com a seguinte configuração:
+
** O volume deve ser configurado como um compartilhamento NFS.
** O sistema de arquivos deve ser configurado com um link. link:../setup/links-overview.html["Saiba mais sobre links"].


* Você precisará considerar os pares de chave/valor das tags que deseja aplicar aos recursos da AWS que fazem parte desta implantação (opcional).
+
link:../fsx-storage/create-discover-systems.html["Aprenda como descobrir ou criar sistemas de arquivos FSx for ONTAP."]
