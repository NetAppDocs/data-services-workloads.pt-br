= Acompanhe os custos dos recursos no NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Use o NetApp Workload Factory para monitorar os custos e o uso do seu sistema de arquivos FSx for ONTAP, para que você possa gerenciar orçamentos e otimizar recursos com eficiência. Usamos o AWS Cost Explorer para fornecer o custo total com dados que exigem permissões mínimas. O custo por recurso (sistema de arquivos ou volume) é baseado em cálculos do Workload Factory, que fornecem insights exclusivos que não estão disponíveis no AWS Cost Explorer.



[[about-this-task]]
== Sobre esta tarefa

O Workload Factory obtém dados de custo e uso para os recursos do seu sistema de arquivos FSx for ONTAP do AWS Cost Explorer usando as seguintes permissões: `ce:GetCostAndUsage` e  `ce:GetTags`. Os seguintes detalhes de custo são monitorados: tipo de uso, SKU de uso, tipo de implantação, uso e custo total.

No painel Cost, duas abas exibem o custo geral e o custo por recurso.

* O custo total é baseado em dados extraídos diretamente da API do AWS Cost Explorer.
* O custo por recurso mostra estimativas de custo por sistema(s) de arquivos e/ou volumes.
+
Para recursos exclusivos, o Workload Factory calcula os custos combinando o uso real do nível de desempenho, uma parcela proporcional dos custos do nível de desempenho alocada ao espaço provisionado, mas não utilizado, as alocações de desempenho distribuídas por capacidade e o uso do pool de capacidade. O Workload Factory multiplica cada componente pelo seu preço por unidade para essa dimensão e soma os resultados para determinar o custo total de cada recurso.



O Workload Factory sempre mostra os dados em uma taxa mensal.

Você pode filtrar os dados de custo e uso por contas da AWS, credenciais, uma ou mais regiões e intervalos de tempo para entender o consumo do seu sistema de arquivos do FSx for ONTAP. Você também pode filtrar por um ou mais sistemas de arquivos e um ou mais volumes dentro de um sistema de arquivos.

As chaves de tag de alocação de custos da AWS e os valores de chave de tag adicionam uma camada adicional de filtragem para identificar custos específicos. Uma tag consiste em uma chave e um valor. Para filtrar por chaves de tag e valores de chave de tag, atribua tags aos seus sistemas de arquivos FSx for ONTAP. link:https://docs.aws.amazon.com/awsaccountbilling/latest/aboutv2/cost-alloc-tags.html["Saiba mais sobre as tags de alocação de custos da AWS."^]

Além dos dados de custos no painel de custos, o resumo executivo de custos gerado por IA mostra os custos do seu sistema de arquivos FSx for ONTAP e os padrões de gastos da sua organização. Você pode gerar arquivos CSV dos recursos do seu sistema de arquivos FSx for ONTAP para compartilhar com sua equipe e partes interessadas.



[[track-costs]]
== Acompanhe os custos

Os custos exibidos no painel de custos do console do Workload Factory são baseados nos dados do AWS Cost Explorer, que são atualizados a cada 24 horas.

.Antes de começar
Verifique se você atende aos seguintes requisitos:

* Você precisa link:add-credentials.html["conceda credenciais com a política de permissão _visualizar, planejar e analisar_"^] no Workload Factory para rastrear os custos do FSx para ONTAP.
* Para filtrar por tags de alocação da AWS, verifique se os seus sistemas de arquivos Amazon FSx for NetApp ONTAP têm tags atribuídas.


.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. No menu *FSx for ONTAP*, selecione *Cost*.
. No painel de custos, filtre os dados de custo e capacidade dos seus recursos FSx for ONTAP fornecendo o seguinte:
+
.. *Contas da AWS*: selecione as contas para as quais você deseja visualizar os dados de custo.
.. *Credenciais*: selecione as credenciais com permissões de _visualização, planejamento e análise_.
.. *Regiões*: selecione as regiões da AWS para as quais você deseja visualizar os dados de custo.
.. *Intervalo de dados de custo*: selecione o intervalo de tempo para visualizar os dados de custo.
.. *Chave de tag de alocação*: (Opcional) Selecione uma chave de tag de alocação e seu valor para gerar um relatório de custos detalhado para todos os sistemas de arquivos FSx for ONTAP associados à tag AWS.
.. *Valores da tag de alocação*: (Opcional) Selecione o valor da chave da tag de alocação que está associado à chave da tag de alocação para gerar um relatório de custos detalhado para todos os sistemas de arquivos FSx for ONTAP associados à tag da AWS.


. Veja os *Detalhes de custo* dos seus recursos do FSx for ONTAP.




[[generate-cost-reports-for-your-fsx-for-ontap-resources]]
== Gere relatórios de custos para seus recursos FSx for ONTAP

Gere relatórios de custos para recursos específicos do sistema de arquivos FSx for ONTAP para compartilhar com as partes interessadas.

.Passos
. No painel de custos, selecione *Gerar relatório*.
. Na tela de Relatório, forneça as seguintes informações:
+
.. *Sistema de arquivos*: Selecione um ou mais sistemas de arquivos FSx for ONTAP para incluir no relatório.
.. *Volume*: (Opcional) selecione um ou mais volumes para incluir no relatório.




.Resultado
O Workload Factory gera um relatório em formato CSV que você pode baixar.
