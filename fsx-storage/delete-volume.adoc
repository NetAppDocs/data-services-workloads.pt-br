= Excluir um volume no NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Exclua um volume do seu sistema de arquivos FSx for ONTAP que não é mais necessário para liberar espaço. Esta operação é irreversível.

.Antes de começar
Considere o seguinte antes de excluir um volume:

* Relações de replicação: você deve link:manage-replication.html["excluir todos os relacionamentos de replicação existentes"] para este volume antes de excluir o volume para que não permaneça nenhuma relação corrompida.
* Instantâneos locais: todos os instantâneos associados a este sistema de arquivos FSx for ONTAP serão excluídos permanentemente.
* Backups de volume: as cópias de backup de volume permanecerão e você ainda poderá usá-las.
* Arquivos imutáveis e snapshots: volumes que contêm arquivos imutáveis e snapshots não podem ser excluídos até o fim do período de retenção.


.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Workloads* > *Volumes explorer*.
. Selecione o menu de ações do volume que você deseja excluir.
. Selecione *Ações básicas* e, em seguida, *Excluir volume*.
. Na caixa de diálogo Delete volume, faça o seguinte:
+
.. Opcionalmente, selecione *Fazer backup do volume* para fazer backup do volume antes de excluí-lo.
+
O backup permanecerá no sistema de arquivos até que você o exclua manualmente.

.. Selecione *Continue*.
.. Digite "delete" para excluir o volume.
.. Selecione *Excluir* para confirmar.
