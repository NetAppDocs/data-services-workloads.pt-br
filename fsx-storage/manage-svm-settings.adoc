= Gerencie as configurações de VMs de armazenamento no NetApp Workload Factory
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Gerencie as configurações de uma máquina virtual de armazenamento no NetApp Workload Factory. Você pode configurar e atualizar o Active Directory para uma máquina virtual de armazenamento, atualizar a senha da máquina virtual de armazenamento e gerenciar as tags da máquina virtual de armazenamento.



[[configure-and-update-ad-for-a-storage-vm-in-netapp-workload-factory]]
== Configure e atualize o Active Directory para uma máquina virtual de armazenamento no NetApp Workload Factory

Configure e atualize o Active Directory para uma VM de armazenamento em um sistema de arquivos FSx for ONTAP no NetApp Workload Factory.

Os mesmos passos se aplicam para configurar e atualizar o Active Directory de uma VM de armazenamento.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. No *FSx for ONTAP*, selecione o menu de ações do sistema de arquivos com a VM de armazenamento que deseja atualizar e, em seguida, selecione *Manage*.
. Na visão geral do sistema de arquivos, em VMs de storage, selecione *Gerenciar*.
. Na tela Gerenciar VMs de armazenamento, selecione o menu de ações da VM de armazenamento para a qual você deseja configurar o Active Directory e, em seguida, selecione *Ações básicas* > *Gerenciar configuração do AD*.
. Na página Manage AD configuration, forneça as seguintes informações:
+
.. *Domínio do Active Directory ao qual você deseja ingressar*: insira o domínio totalmente qualificado (FQDN) do seu Active Directory.
.. *Endereços IP de DNS*: insira até três endereços IP separados por vírgulas.
.. *Nome NetBIOS do servidor SMB*: insira o nome NetBIOS do servidor SMB do objeto de computador do Active Directory a ser criado para a sua storage VM. Esse é o nome dessa SVM no Active Directory.
.. *Nome de usuário*: insira o nome de usuário da conta de serviço no seu Active Directory existente.
+
Não inclua prefixo ou sufixo de domínio. Para  `EXAMPLE\ADMIN`, use  `ADMIN`.

.. *Senha*: digite a senha da conta de serviço.
.. *Unidade organizacional (UO)*: insira a unidade organizacional.
+
A OU (Unidade Organizacional) é o nome distinto do caminho da unidade organizacional à qual você deseja associar seu sistema de arquivos.

.. *Grupo de administradores delegados*: opcionalmente, insira o grupo de administradores delegados do sistema de arquivos.
+
O grupo de administradores delegados é o nome do grupo no seu Active Directory que pode administrar seu sistema de arquivos.

+
Se você estiver usando o AWS Managed Microsoft AD, deverá especificar um grupo, como AWS Delegated FSx Administrators, AWS Delegated Administrators ou um grupo personalizado com permissões delegadas para a unidade organizacional (OU).

+
Se você estiver se conectando a um AD autogerenciado, use o nome do grupo no seu AD. O grupo padrão é `Domain Admins`.



. Selecione *Aplicar*.




[[manage-storage-vm-tags]]
== Gerenciar tags de VM de armazenamento

As tags ajudam você a categorizar seus recursos. Você pode adicionar, editar e remover tags de uma máquina virtual de armazenamento a qualquer momento no NetApp Workload Factory.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. No *FSx for ONTAP*, selecione o menu de ações do sistema de arquivos com a VM de armazenamento que deseja atualizar e, em seguida, selecione *Manage*.
. Na visão geral do sistema de arquivos, em VMs de storage, selecione *Gerenciar*.
. Na tela Gerenciar VMs de armazenamento, selecione o menu de ações da VM de armazenamento para a qual deseja editar as tags e, em seguida, selecione *Ações básicas* > *Editar tags da VM de armazenamento*.
. Na página Editar tags da VM de armazenamento, adicione, edite ou remova as tags.
+
O número máximo de tags que você pode aplicar a uma VM de armazenamento é 50.

. Selecione *Aplicar*.




[[reset-the-storage-vm-password-in-netapp-workload-factory]]
== Redefina a senha da VM de armazenamento no NetApp Workload Factory

Redefina a senha de uma máquina virtual de armazenamento no NetApp Workload Factory quando necessário.

.Passos
. Faça login no link:https://console.netapp.com["NetApp Console"^].
. Selecione o menu image:workloads-menu-icon.png["O ícone do menu hambúrguer é usado para navegar até \"Workloads\", o item de menu do Workload Factory"], *Workloads* > *Storage* > *FSx for ONTAP*.
. No *FSx for ONTAP*, selecione o menu de ações do sistema de arquivos com a senha da VM de armazenamento que deseja redefinir e, em seguida, selecione *Gerenciar*.
. Na visão geral do sistema de arquivos, em VMs de storage, selecione *Gerenciar*.
. Na tela Gerenciar VMs de armazenamento, selecione o menu de ações da VM de armazenamento para a qual deseja redefinir a senha e, em seguida, selecione *Ações básicas* > *Redefinir senha*.
. Na caixa de diálogo Reset password, forneça o seguinte:
+
.. *Nova senha*: digite uma nova senha para a VM de armazenamento.
.. *Confirmar senha*: digite a nova senha novamente para confirmar.
